# 📊 Painel de Indicadores Financeiros — Controladoria

Um dashboard financeiro interativo desenvolvido em HTML5, JavaScript e Chart.js para simulação e acompanhamento de indicadores financeiros em tempo real.

## 🚀 Funcionalidades

- **Simulação Dinâmica:** Entrada de dados de Receitas, Custos, Líquido Anterior e Saldo Acumulado.
- **Cálculo de EBITDA e Margem Líquida:** Indicadores recalculados automaticamente conforme os valores inseridos.
- **Gráfico Comparativo (Barras):** Comparação entre o Mês Anterior e Mês Atual.
- **Gráfico de Custos Inteligente (Rosca):** Redistribuição adaptativa de até ±10% do orçamento com base no resultado líquido (lucro ou prejuízo).
- **Interface Responsiva:** Design moderno focado na experiência executiva.

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Chart.js & Chart.js DataLabels Plugin**

## 📄 Como Executar

Basta descarregar ou clonar o repositório e abrir o ficheiro `painel.html` em qualquer navegador web.
